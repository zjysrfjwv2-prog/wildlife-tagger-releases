# Wildlife Tagger

A Mac app (Apple silicon, macOS 14+) that identifies the wildlife in your photos and writes keywords, captions and focus checks to XMP for Adobe Bridge.

**Download:** get `Wildlife Tagger.zip` from the [latest release](../../releases/latest), unzip it, and move Wildlife Tagger to Applications. The first time, right-click the app and choose Open.

After that, updates arrive inside the app: Wildlife Tagger › Check for Updates…
